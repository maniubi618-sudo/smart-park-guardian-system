# 局域网手机摄像头监控系统使用说明书

## 1. 系统介绍

本系统是一个基于Web技术的局域网手机摄像头监控系统，允许您将手机作为远程摄像头，在PC端实时查看监控画面。

### 核心功能
- 📱 手机摄像头实时推流
- 💻 PC端实时监控
- 🔄 支持多观看端同时访问
- 🔀 摄像头切换（前置/后置）
- 💡 闪光灯控制
- 📷 拍照功能
- 📊 实时状态监控

### 技术特点
- 低延迟视频传输
- 自适应视频质量
- 赛博朋克风格UI
- 响应式设计
- 易于部署和使用

## 2. 系统要求

### 硬件要求
- 一台运行Node.js的电脑
- 一部支持WebRTC的智能手机
- 同一局域网网络环境

### 软件要求
- Node.js 12.0+（推荐14.0+）
- 现代浏览器（Chrome、Firefox、Edge等）

## 3. 安装部署

### 3.1 下载项目

将项目文件下载到本地目录，例如：
```
c:\Users\cry\Desktop\phone-camera-stream
```

### 3.2 安装依赖

打开命令行工具，进入项目目录，执行以下命令：

```bash
# 进入项目目录
cd c:\Users\cry\Desktop\phone-camera-stream

# 安装依赖
npm install
```

### 3.3 启动服务器

执行以下命令启动服务器：

```bash
# 启动服务器
npm start
```

服务器启动后，会显示以下信息：

```

     https://localhost:3443

  📱 手机端连接地址:
     https://192.168.1.100:3443/phone.html

     浏览器提示"不安全" → 点击"继续前往"
```

## 4. 使用方法

### 4.1 连接流程

1. **确保网络环境**：确保手机和PC在同一局域网内

2. **打开PC监控页面**：
   - 在PC浏览器中打开 `https://localhost:3443`
   - 首次访问会提示"不安全"，点击"继续前往"信任证书

3. **连接手机摄像头**：
   - 在手机浏览器中输入服务器显示的手机连接地址（例如：`https://192.168.1.100:3443/phone.html`）
   - 首次访问同样需要信任证书
   - 点击"启用摄像头"按钮
   - 授权浏览器访问摄像头权限

4. **开始监控**：
   - 手机连接成功后，PC端会自动显示手机摄像头画面
   - 可以在手机端调整摄像头设置

### 4.2 手机端操作

| 功能 | 操作 | 说明 |
|------|------|------|
| 切换摄像头 | 点击"翻转"按钮 | 在前置和后置摄像头之间切换 |
| 闪光灯 | 点击"闪光灯"按钮 | 开启/关闭闪光灯（需硬件支持） |
| 拍照 | 点击中央拍照按钮 | 拍摄并下载照片 |
| 静音 | 点击"静音"按钮 | 开启/关闭麦克风 |
| 断开连接 | 点击"断开"按钮 | 断开连接并刷新页面 |

### 4.3 PC端操作

| 功能 | 操作 | 说明 |
|------|------|------|
| 显示模式 | 点击"适应屏幕"或"拉伸填充" | 切换视频显示模式 |
| 网格线 | 点击"网格线"按钮 | 显示/隐藏网格线 |
| 水平翻转 | 点击"水平翻转"按钮 | 水平镜像显示画面 |
| 全屏 | 点击"全屏"按钮 | 进入/退出全屏模式 |
| 复制连接地址 | 点击侧边栏的手机连接地址 | 复制地址到剪贴板 |

## 6. 常见问题与解决方案

### 6.1 无法访问摄像头
- **问题**：手机端提示"无法访问摄像头"
- **解决方案**：
  1. 检查浏览器是否有权限访问摄像头
  2. 检查系统设置是否允许浏览器访问摄像头
  3. 尝试使用其他浏览器

### 6.2 连接断开
- **问题**：WebSocket连接经常断开
- **解决方案**：
  1. 检查网络连接是否稳定
  2. 确保手机和PC在同一局域网
  3. 尝试重启服务器

### 6.3 视频延迟高
- **问题**：视频画面延迟较高
- **解决方案**：
  1. 确保网络连接稳定
  2. 减少网络拥塞
  3. 尝试降低视频分辨率

### 6.4 证书警告
- **问题**：浏览器显示证书警告
- **解决方案**：
  1. 这是正常现象，因为使用的是自签名证书
  2. 点击"继续前往"或"高级"->"继续访问"
  3. 生产环境中建议使用可信的SSL证书

## 7. 性能优化建议

### 7.1 网络优化
- 使用5GHz Wi-Fi网络，减少干扰
- 确保网络带宽充足
- 避免同时进行大流量网络操作

### 7.2 设备优化
- 确保手机电量充足
- 关闭手机后台运行的其他应用
- 保持手机冷却，避免过热

### 7.3 服务器优化
- 确保服务器性能足够
- 关闭不必要的服务
- 定期重启服务器以释放资源

## 8. 安全注意事项

### 8.1 网络安全
- 仅在信任的局域网中使用
- 避免在公共网络中使用
- 定期更改网络密码

### 8.2 隐私保护
- 确保监控范围符合隐私规定
- 不在敏感区域使用
- 定期检查监控画面

### 8.3 系统安全
- 定期更新Node.js和依赖包
- 使用防火墙保护服务器
- 限制服务器访问权限

### 9.2 自定义配置

可以修改以下配置项：

1. **服务器端口**：在`server.js`中修改`HTTPS_PORT`和`HTTP_PORT`
2. **视频质量**：在`phone.html`中修改`toBlob`的质量参数
3. **帧间隔**：在`phone.html`中修改`FRAME_INTERVAL`
4. **最大分辨率**：在`phone.html`中修改`Math.min(vw, 1280)`

## 10. 故障排查

### 10.1 服务器启动失败
- 检查端口是否被占用
- 检查依赖是否安装完整
- 检查Node.js版本是否符合要求

### 10.2 手机无法连接
- 检查手机和PC是否在同一局域网
- 检查防火墙是否阻止连接
- 检查服务器是否正常运行

### 10.3 视频不显示
- 检查手机摄像头是否正常工作
- 检查WebSocket连接是否正常
- 检查浏览器控制台是否有错误信息
