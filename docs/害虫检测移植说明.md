
# 害虫检测功能移植说明
================================

## 📋 概述

已成功将 yolopest 的害虫检测功能移植到我们的园区智能安防系统。

---

## 📦 新增文件

1. `app/services/pest_detector.py` - 害虫检测器服务类
2. `app/api/v1/endpoints/pest_detection.py` - 害虫检测API接口
3. `copy_model.py` - 模型文件复制脚本
4. `docs/害虫检测移植说明.md` - 本文档

---

## 🔧 修改的文件

1. `app/services/detection_service.py` - 集成了害虫检测功能
2. `app/objects/alarm_case.py` - 更新了告警类型描述
3. `app/main.py` - 注册了害虫检测API路由

---

## 🚀 使用方法

### 1️⃣ 首先复制模型文件

运行以下命令复制模型：

```bash
python copy_model.py
```

或者手动复制：

```
从: app/models/yolopest-main/backend/model_weights/best.pt
到: app/models/pest_detector.pt
```

### 2️⃣ 启动服务

```bash
python -m app.main
```

### 3️⃣ 使用API测试

#### 使用 API 文档页面: http://localhost:8089/docs

接口：

| 接口 | 说明 |
|-----|-----|
| POST /api/v1/pest-detection/detect | 上传图像进行害虫检测 |
| GET /api/v1/pest-detection/status | 查看模型状态 |

### 4️⃣ 摄像头配置告警

在摄像头配置界面选择告警类型为 **"害虫检测"**（类型 3），系统会自动进行害虫检测并告警。
