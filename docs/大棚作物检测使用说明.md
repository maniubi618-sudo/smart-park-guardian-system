
# 大棚作物检测功能使用说明

## 概述

我们已经成功为项目添加了大棚作物检测功能，包括：
- **作物病虫害检测**（告警类型 3）
- **作物长势异常检测**（告警类型 4）
- **果实成熟度检测**（告警类型 5）

## 已完成的工作

### 1. 更新的文件
- `app/services/detection_service.py` - 添加了作物检测逻辑
- `app/objects/alarm_case.py` - 更新了告警类型定义
- `app/models/README.md` - 添加了模型说明文档
- `tools/` 目录 - 添加了训练脚本

### 2. 新增的训练脚本
在 `tools/` 目录下有以下脚本：
- `convert_plantvillage.py` - 转换 PlantVillage 数据集到检测格式
- `prepare_plantvillage.py` - 从 Hugging Face 准备数据集
- `train_plantvillage.py` - ⭐ 训练 PlantVillage 分类模型（推荐）
- `train_crop_model.py` - 训练检测模型
- `README.md` - 详细使用说明

## 下一步：训练模型

### 方法一：用 PlantVillage 训练分类模型（推荐）

我们已经有了 PlantVillage 数据集！直接运行：

```bash
cd tools
python train_plantvillage.py "../app/models/PlantVillage-Dataset-master" --model s --epochs 50
```

参数说明：
- `--model` - 模型大小：n (小), s (中小), m (中), l (大)
- `--epochs` - 训练轮数：先用 10-20 试试，效果好再加

训练完成后，模型会自动复制到 `app/models/crop_pest.pt`！

### 方法二：训练检测模型

如果你有标注好的检测数据集（有 bounding box），可以用：

```bash
cd tools
# 先准备数据集（YOLO 格式）
python convert_plantvillage.py "<数据集路径>" "../datasets/crop_pest"

# 然后训练
python train_crop_model.py "../datasets/crop_pest/crop_pest.yaml"
```

## 使用方法

### 1. 训练模型后

训练完成后，模型会自动保存到 `app/models/crop_pest.pt`。

### 2. 重启服务

重启后端服务，模型会自动加载。

### 3. 在前端配置

在摄像头配置中，选择相应的告警类型：
- **作物病虫害** - 使用模型 `crop_pest.pt`
- **作物长势异常** - 使用模型 `crop_growth.pt`（需要单独训练）
- **果实成熟度** - 使用模型 `crop_fruit.pt`（需要单独训练）

## 常见问题

### Q: 训练需要多长时间？
A: 取决于硬件配置：
- CPU - 非常慢，不建议
- 中端 GPU (4-8GB) - 几小时
- 高端 GPU - 不到 1 小时

### Q: 显存不足怎么办？
A: 减小 batch size 或用更小的模型：
```bash
python train_plantvillage.py "<数据集路径>" --model n --epochs 20
```

### Q: 模型文件放在哪里？
A: 训练完成后会自动复制到 `app/models/` 目录，或者手动把 `.pt` 文件放进去。

### Q: 如何判断模型好坏？
A: 训练过程中会显示准确率，Top-1 Accuracy 至少要 80% 以上才算好。
